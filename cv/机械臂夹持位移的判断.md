在实际生产中时候，我们需要计算安全系数，只有sf = 抓取能提供最大的抗滑能力 / 实际所需要的切向力，sf > 1 的时候才不会滑动。

这有三种等价的写法，现场取决于使用手上的什么数据：

|写法|公式|适用场景|
|---|---|---|
|力比（最常用）|`SF = 2μN / F_req`|已知夹持力和 μ|
|摩擦比|`SF = μ_avail / μ_req`，`μ_req = F_t / N`|只有力传感器，反推需要多少 μ|
|加速度比（现场最好用）|`SF = a_max_tolerable / a_actual`|直接回答“能开多快”|

## 生产上 μ 和 N 从哪来

μ 不能查表。 手册值是在理想表面测的，实际带油污或磨损后会掉一大截。标准做法：

斜面法：把工件放在同材质斜板上，匀速抬升角度，记录**刚起滑**的角度 θ，`μ = tan θ`。测 5 次取中位数。

拉力法：夹住工件，用测力计水平拉，记录起滑瞬间的力 `F_slip`，`μ = F_slip / N`。同时得到 μ 和滑移的初始特征。

**设计值取实测的 60~70%**，为油污、磨损、湿度、温升留余量。**N 不能取标称值。 位置控制夹爪真正的旋钮是**过盈量 δ（over-travel）：先闭合到刚接触，再额外压 δ，`N = k · δ`。你现在的仿真里这个 `k` 是 25 N/m（单指），所以球卡在 4cm 时 N≈0.93 N，这就是“闭到底”的自然结果。力控夹爪则直接读力传感。

这是三种不同的物理情况。

|形态|时间尺度|成因|怎么办|
|---|---|---|---|
|一次性沉降|<0.5 s 内到位后变平|接触安定 + 物体转动到新平衡|**正常，不用调**|
|持续滑移|位移单调增长，速度不收敛|SF < 1|加过盈量 / 换指垫 / 降加速度|
|蠕变|几十秒到几分钟缓慢爬升|聚合物指垫应力松弛|降夹持应力 / 缩短悬挂时间|

判定靠斜率，不靠绝对值。 采样 10~30 Hz 记录物体相对夹爪的位姿，看 `dΔs/dt` 是否在 200~500 ms 内收敛到 0。曲线①和②前 100 ms 长得一样，两秒后就是两种情况了。

所以“阈值 2 mm”只能当报警线，不能当判据。

指垫切向刚度 `k_c ≈ G·A/t`。橡胶 G≈1 MPa，接触面积 2 cm²，垫厚 3 mm → `k_c ≈ 33 N/mm`。要靠弹性拉出 1 mm，需要 33 N 的切向力；而 35 g 的球只需要 0.34 N，对应位移 **12 μm**。

根据计算方式来计算，如果一个球直径是40mm，需要被撑在两指之间，那么指尖垫内表面距离就是40mm，垫本身有1.5mm。于是：q1 + q2 + 0.003 = 0.040   →   q1 = q2 = 18.5 mm

在mujoco的仿真器里，执行器是保守弹簧（`panda.xml:276`，肌腱空间 k=100 N/m，映射到单指 50 N/m）。肌腱长度等于单指位移，所以：N = 50 × (q_act − q_cmd)        单位 N，位移用 m

`q_cmd = 0` 时 `N = 50 × 0.0185 = 0.925 N`，这已是这个夹爪对 4 cm 球能提供的**上限**。

需求侧：

```
SF = 2μN / m(g + a)     →     N_req = m(g+a) / (2μ)
m(g+a) = 0.035 × (9.81 + 1.7) = 0.403 N
```

联立得到 q_cmd 的上限：

```
q_cmd ≤ 0.0185 − [m(g+a) / (100μ)]
```
